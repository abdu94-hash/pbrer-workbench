# PBRER Workbench

Free companion tool to *The PBRER Handbook* by Hafez Selim, MD, PhD (Selim Medical Press).

Single offline HTML page. All calculations run in the browser; nothing is uploaded or stored.

## Publish on GitHub Pages
1. Create a public repository named `pbrer-workbench` under the `abdu94-hash` account.
2. Upload `index.html`, `.nojekyll`, `robots.txt`, and this README.
3. Settings → Pages → Deploy from branch → `main` / root → Save.
4. The tool will be live at https://abdu94-hash.github.io/pbrer-workbench/ (the address printed in the book).
